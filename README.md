# 360GS Prototype v0.2d

360°写真、360°動画、3D Gaussian Splattingを、専門的な設定なしでブラウザ上から扱うためのプロトタイプです。

## この版でできること

### 360°写真

- JPEG / PNG / WebPの360°写真を選ぶだけで表示
- 2:1の360°画像らしいかを自動確認
- ブラウザ内で自由に見回す

### 3DGS

- `.ply`、`.compressed.ply`、`.sog` を選ぶだけで表示
- ドラッグで回転、ホイールで拡大縮小
- モデルの大きさに合わせて初期視点を自動調整
- PlayCanvas公式サンプルで動作確認可能

### 360°動画

- Insta360 Studioなどから書き出したMP4等を選択またはドラッグで読み込む
- 縦横比、解像度、長さを自動確認
- 最大12枚の確認用代表画像を自動抽出
- 動画時間に応じて短時間・標準・長時間モードを自動選択
- 全体を粗く確認し、つながりが弱い区間だけ中間フレームを追加する適応型連続性解析
- 360°キーフレームを前・右・後・左の4方向の透視画像へ変換
- 局所特徴点を抽出し、隣接キーフレーム間の対応点を自動探索
- 対応点を360°カメラ座標の3次元単位方向ベクトルへ戻す
- RANSACで幾何学的に矛盾する対応点を除外
- Essential matrixから隣接キーフレーム間の相対回転と移動方向を推定
- 幾何学的内点率、視差角、姿勢推定の成立状況を表示
- 相対移動方向を連結した「距離スケールなし」の仮軌跡を表示

## 動画時間が異なる場合

利用者が解析間隔を設定する必要はありません。数十秒から約15分程度までを想定し、動画時間に合わせて内部処理量を自動調整します。

### 連続性解析

- 60秒以下: 最大約36フレーム
- 1〜5分: 最大約90フレーム
- 5分超: 最大約180フレーム

### 局所特徴点解析

- 60秒以下: 最大18キーフレーム
- 1〜5分: 最大28キーフレーム
- 5分超: 最大40キーフレーム

### v0.2d 相対姿勢解析

相対姿勢推定は粗いキーフレームから開始し、姿勢推定が弱い区間だけ中間フレームを追加します。現在の内部上限は概ね次のとおりです。

- 60秒以下: 最大30キーフレーム
- 1〜5分: 最大56キーフレーム
- 5分超: 最大90キーフレーム

長時間動画でも全フレームをメモリへ保持しません。

## v0.2dの相対カメラ姿勢推定

局所特徴点は4枚の透視画像上で検出しますが、幾何計算では透視画像の座標をそのまま使いません。既知の画角と各透視方向から、各対応点を360°カメラ中心から見た3次元単位方向ベクトルへ変換します。

対応点から中央投影カメラのエピポーラ拘束を構成し、8点法をRANSAC内で反復します。外れ対応を除いた後にEssential matrixを再推定し、特異値制約を適用して相対回転と移動方向へ分解します。複数候補は正の奥行きになる対応点の割合で選択します。

画面の「幾何学的内点率」は、推定したエピポーラ幾何に整合した対応点の割合です。「視差角」は、推定回転を除いた後に残る方向差の中央値です。純回転や視差不足では3D復元に必要な並進が確定できないため、弱い判定になります。

### 重要な制約

v0.2dで求まる移動量は方向のみです。単眼映像の相対姿勢だけではメートル単位の絶対距離スケールは決まりません。そのため画面の軌跡は各区間を同じ長さとして描いた形状確認用であり、実距離・実縮尺を示しません。

また、現在の相対姿勢は隣接区間ごとの推定です。長い動画では誤差が累積するため、次段階でループ閉合、再訪位置、全体最適化、自動区間分割を追加して軌跡を安定化する必要があります。

## プライバシー

自分で選択した360°写真、360°動画、3DGSファイルはサーバーへアップロードせず、端末内のブラウザだけで処理します。代表画像、透視画像、局所特徴点、相対姿勢の中間データも現段階では外部へ送信しません。

## この版ではまだできないこと

- メートル単位のカメラ移動距離を確定する
- 長時間動画の軌跡をループ閉合・Bundle Adjustment等で全体最適化する
- 360°動画から3DGSを最後まで自動生成する
- Cloudflare R2へ保存する
- メール認証で限定共有する
- 作成した3DGSをオンライン上で永続保存する

## 使い方

1. GitHub Pagesの360GSを開く
2. 「360°写真を見る」「3DGSファイルを見る」「360°動画から3Dを作る」のいずれかを選ぶ
3. ファイルを選ぶ
4. 画面の案内に従う

360°動画では、Insta360 Studioから書き出した2:1のMP4を推奨します。解析間隔、動画時間、RANSAC等の設定を利用者が行う必要はありません。

## 技術構成

- HTML / CSS / JavaScript
- Photo Sphere Viewer 5.15.0
- Three.js 0.179.1
- PlayCanvas Engine 2.21.4
- HTMLVideoElement / Canvasによるローカル動画解析
- 適応型equirectangular連続性チェック
- equirectangularから4方向の透視画像への変換
- 軽量コーナー検出、正規化パッチ記述子、相互最近傍マッチング
- 360°bearing vectorへの逆投影
- RANSAC + 8点法 + Essential matrix制約
- Cheiralityによる相対姿勢候補選択

利用者が理解する必要のない専門用語や設定項目は通常画面から隠します。基本操作は今後も「ファイルを選ぶ → 自動処理 → 見る → 必要なら共有する」とします。
