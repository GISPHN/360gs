# 360GS Prototype v0.2e

360°写真、360°動画、3D Gaussian Splattingを、専門的な設定なしでブラウザ上から扱うためのプロトタイプです。

## この版でできること

### 360°写真

- JPEG / PNG / WebPの360°写真を選ぶだけで表示
- 2:1の360°画像らしいかを自動確認
- ブラウザ内で自由に見回す

### 3DGS

- `.ply`、`.compressed.ply`、`.sog` を選ぶだけで表示
- ドラッグで回転、ホイールで拡大縮小
- モデルの大きさに合わせて初期視点を自動調整
- PlayCanvas公式サンプルで動作確認可能

### 360°動画

- Insta360 Studioなどから書き出したMP4等を選択またはドラッグで読み込む
- 縦横比、解像度、長さを自動確認
- 最大12枚の確認用代表画像を自動抽出
- 動画時間に応じて短時間・標準・長時間モードを自動選択
- 全体を粗く確認し、つながりが弱い区間だけ中間フレームを追加する適応型連続性解析
- 360°キーフレームを前・右・後・左の4方向の透視画像へ変換
- 局所特徴点を抽出し、隣接キーフレーム間の対応点を自動探索
- 対応点を360°カメラ座標の3次元単位方向ベクトルへ戻す
- RANSACで幾何学的に矛盾する対応点を除外
- Essential matrixから隣接キーフレーム間の相対回転と移動方向を推定
- 幾何学的内点率、視差角、姿勢推定の成立状況を表示
- 相対移動方向を連結した「距離スケールなし」の仮軌跡を表示
- 姿勢推定が弱い区間を自動的な分割境界候補として検出
- 連続して安定する区間を区間単位で再評価し、「良好候補 / 3D化候補 / 保留」に分類
- 各候補区間の開始・終了時刻、長さ、姿勢区間数、内点率中央値、視差角中央値を表示
- 動画全体について「まず何区間に分けて3D化すべきか」を自動提案

## 動画時間が異なる場合

利用者が解析間隔を設定する必要はありません。数十秒から約15分程度までを想定し、動画時間に合わせて内部処理量を自動調整します。

### 連続性解析

- 60秒以下: 最大約36フレーム
- 1〜5分: 最大約90フレーム
- 5分超: 最大約180フレーム

### 局所特徴点解析

- 60秒以下: 最大18キーフレーム
- 1〜5分: 最大28キーフレーム
- 5分超: 最大40キーフレーム

### 相対姿勢解析

相対姿勢推定は粗いキーフレームから開始し、姿勢推定が弱い区間だけ中間フレームを追加します。現在の内部上限は概ね次のとおりです。

- 60秒以下: 最大30キーフレーム
- 1〜5分: 最大56キーフレーム
- 5分超: 最大90キーフレーム

長時間動画でも全フレームをメモリへ保持しません。

## v0.2dの相対カメラ姿勢推定

局所特徴点は4枚の透視画像上で検出しますが、幾何計算では透視画像の座標をそのまま使いません。既知の画角と各透視方向から、各対応点を360°カメラ中心から見た3次元単位方向ベクトルへ変換します。

対応点から中央投影カメラのエピポーラ拘束を構成し、8点法をRANSAC内で反復します。外れ対応を除いた後にEssential matrixを再推定し、特異値制約を適用して相対回転と移動方向へ分解します。複数候補は正の奥行きになる対応点の割合で選択します。

画面の「幾何学的内点率」は、推定したエピポーラ幾何に整合した対応点の割合です。「視差角」は、推定回転を除いた後に残る方向差の中央値です。純回転や視差不足では3D復元に必要な並進が確定できないため、弱い判定になります。

### 絶対スケールについて

相対姿勢で求まる移動量は方向のみです。単眼映像の相対姿勢だけではメートル単位の絶対距離スケールは決まりません。そのため画面の軌跡は各区間を同じ長さとして描いた形状確認用であり、実距離・実縮尺を示しません。

## v0.2eの自動区間分割

v0.2eでは、隣接キーフレームごとの相対姿勢結果をそのまま1本の軌跡として無理に連結しません。

各区間について、次を再評価します。

- 姿勢推定の状態（良好 / 要確認 / 弱い）
- 幾何学的内点率
- 視差角
- 安定区間の連続長
- 区間内で良好判定が占める割合

姿勢推定が弱い区間、内点率が非常に低い区間、視差が不足する区間を分割境界候補として扱います。境界に挟まれた連続区間を改めて評価し、一定以上の長さ・内点率・視差を持つ区間だけを3D化候補として残します。

現在の初期基準は次のとおりです。

- 分割境界候補: 姿勢推定が弱い、内点率25%未満、または視差角0.16°未満
- 3D化候補: 2姿勢区間以上、約1.2秒以上、内点率中央値30%以上、視差角中央値0.16°以上
- 良好候補: 3姿勢区間以上、内点率中央値45%以上、視差角中央値0.45°以上、かつ良好判定が区間内の50%以上

これらはプロトタイプの初期閾値です。今後、複数の実動画と実際の3DGS生成成功率を照合して校正します。

重要: v0.2eの「区間再評価」は、直前にRANSAC / Essential matrixで求めた相対姿勢結果を区間単位で再評価する処理です。各候補区間でBundle Adjustmentや全キーフレームの姿勢をゼロから解き直す処理はまだ実装していません。次段階で、候補区間内への追加キーフレーム投入、局所SfM、ループ閉合、全体最適化へ進みます。

## プライバシー

自分で選択した360°写真、360°動画、3DGSファイルはサーバーへアップロードせず、端末内のブラウザだけで処理します。代表画像、透視画像、局所特徴点、相対姿勢、自動区間分割の中間データも現段階では外部へ送信しません。

## この版ではまだできないこと

- メートル単位のカメラ移動距離を確定する
- 候補区間内でBundle Adjustment等による局所SfMの全体最適化を行う
- 分割した複数区間の再訪位置を検出して自動接続する
- 360°動画から3DGSを最後まで自動生成する
- Cloudflare R2へ保存する
- メール認証で限定共有する
- 作成した3DGSをオンライン上で永続保存する

## 使い方

1. GitHub Pagesの360GSを開く
2. 「360°写真を見る」「3DGSファイルを見る」「360°動画から3Dを作る」のいずれかを選ぶ
3. ファイルを選ぶ
4. 画面の案内に従う

360°動画では、Insta360 Studioから書き出した2:1のMP4を推奨します。解析間隔、動画時間、RANSAC、分割閾値等の設定を利用者が行う必要はありません。

## 技術構成

- HTML / CSS / JavaScript
- Photo Sphere Viewer 5.15.0
- Three.js 0.179.1
- PlayCanvas Engine 2.21.4
- HTMLVideoElement / Canvasによるローカル動画解析
- 適応型equirectangular連続性チェック
- equirectangularから4方向の透視画像への変換
- 軽量コーナー検出、正規化パッチ記述子、相互最近傍マッチング
- 360°bearing vectorへの逆投影
- RANSAC + 8点法 + Essential matrix制約
- Cheiralityによる相対姿勢候補選択
- 相対姿勢・内点率・視差角を用いた自動区間分割と区間品質再評価

利用者が理解する必要のない専門用語や設定項目は通常画面から隠します。基本操作は今後も「ファイルを選ぶ → 自動処理 → 見る → 必要なら共有する」とします。
