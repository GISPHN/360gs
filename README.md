# 360GS Prototype v0.2c

360°写真、360°動画、3D Gaussian Splattingを、専門的な設定なしでブラウザ上から扱うためのプロトタイプです。

## この版でできること

### 360°写真

- JPEG / PNG / WebPの360°写真をファイル選択またはドラッグで読み込む
- 画像の縦横比を確認し、360°写真らしくない画像をわかりやすく警告する
- ブラウザ内で自由に見回す

### 3DGS

- 3D Gaussian Splattingの `.ply`、`.compressed.ply`、`.sog` を選択またはドラッグで読み込む
- 読み込んだ3D空間をドラッグで回転し、ホイールで拡大縮小する
- モデルの大きさを自動確認し、最初のカメラ位置を自動調整する
- PlayCanvas公式のサンプル3Dで、3DGSファイルを持っていなくても動作確認する

### 360°動画

- Insta360 Studioなどから書き出したMP4等を選択またはドラッグで読み込む
- 動画の縦横比、解像度、長さを自動確認する
- 一般的な2:1 equirectangular 360°動画かを自動判定する
- 動画全体から最大12枚の代表画像を自動抽出する
- 代表画像とは別に、低解像度の内部解析フレームを使って画像同士の連続性を確認する
- 動画時間に応じて「短時間」「標準」「長時間」の解析モードを自動選択する
- 画像のつながりが弱い区間だけ中間フレームを追加する適応型解析を行う
- 解析結果を動画全体のタイムラインとして「良好 / 要確認 / 弱い」で表示する
- 連続性チェックで選ばれたキーフレームを前・右・後・左の4方向の透視画像へ変換する
- 透視画像から局所特徴点を抽出し、隣接キーフレーム間で対応点を自動探索する
- 局所対応点の多寡をタイムラインとして表示する
- 対応点の動きから「視差候補」を予備指標として表示する

## 動画時間が異なる場合の方針

数十秒の短い動画から約15分程度の長い動画まで、利用者が解析間隔を設定しなくても扱えることを設計条件としています。

画面に表示する代表画像は、動画の長さにかかわらず最大12枚程度に抑えます。これらは確認用プレビューであり、3D化の内部解析に使うフレーム数とは分離しています。

連続性解析は固定1秒間隔ではありません。最初に動画全体を粗く確認し、画像間のつながりが弱い区間だけ中間フレームを追加します。

現在の連続性解析の上限は概ね次のとおりです。

- 60秒以下: 最大約36フレーム
- 1〜5分: 最大約90フレーム
- 5分超: 最大約180フレーム

v0.2cの局所特徴点解析では、連続性解析で得られた全フレームを再び高負荷で処理するのではなく、動画時間に応じて次の上限までキーフレームを選びます。

- 60秒以下: 最大18キーフレーム
- 1〜5分: 最大28キーフレーム
- 5分超: 最大40キーフレーム

長時間動画では、つながりが弱い区間を優先しつつ動画全体を代表するようキーフレームを選択します。透視画像そのものは保存せず、局所特徴点と対応判定に必要な小さな中間データのみを保持します。

## v0.2bの連続性チェックについて

360° equirectangular画像の上下端を除いた範囲を低解像度化して比較し、横方向の循環ずれを補正しながら画像間の類似性を評価します。これにより、カメラの向きが変わった場合でも、次の撮影位置推定へ進めるだけの画像の連続性がありそうかを事前確認します。

この判定はヒューリスティックな事前チェックであり、3D再構成の成功を保証するものではありません。

## v0.2cの局所特徴点チェックについて

360°画像の強い歪みをそのまま特徴点比較に使わず、各キーフレームを水平4方向の透視画像へ展開します。各透視画像からコーナー状の局所特徴を抽出し、明るさを正規化した小さなパッチ記述子を作り、相互最近傍と距離比によって対応候補を絞り込みます。

v0.2cは、実際のカメラ位置・向きをまだ計算しません。画面に表示する「視差候補」は、対応点の動きが単純な一様移動だけでは説明しにくい区間を予備的に示すものです。これは並進や奥行きを確定する指標ではなく、次の幾何学的姿勢推定へ進むための診断値です。

次段階では、局所対応点に対して幾何学的な外れ値除去、相対回転・並進方向の推定、連続フレームへの姿勢伝播、必要に応じた自動区間分割を追加します。

### プライバシー

自分で選択した360°写真、360°動画、3DGSファイルはサーバーへアップロードせず、端末内のブラウザだけで読み込みます。

## この版ではまだできないこと

- 360°動画から実際のカメラ位置・向きを復元する
- 360°動画から3DGSを最後まで自動生成する
- Cloudflare R2へ保存する
- メール認証で限定共有する
- 作成した3DGSをオンライン上で永続保存する

## 使い方

1. GitHub Pagesの360GSを開く
2. 「360°写真を見る」「3DGSファイルを見る」「360°動画から3Dを作る」のいずれかを選ぶ
3. ファイルを選ぶ
4. 画面の案内に従う

360°動画では、Insta360 Studioから書き出した2:1のMP4を推奨します。解析間隔や動画時間の設定は不要です。

## 技術構成

- HTML / CSS / JavaScript
- Photo Sphere Viewer 5.15.0
- Three.js 0.179.1
- PlayCanvas Engine 2.21.4
- HTMLVideoElement / Canvasによるローカル動画解析・代表フレーム抽出
- 低解像度equirectangular画像の循環シフト補正を用いた適応型連続性チェック
- equirectangular画像から4方向の透視画像へのローカル変換
- ブラウザ内の軽量コーナー検出・正規化パッチ記述子・相互対応点探索

利用者が理解する必要のない専門用語や設定項目は通常画面から隠します。今後も「ファイルを選ぶ → 自動処理 → 見る → 必要なら共有する」という操作を基本にします。
