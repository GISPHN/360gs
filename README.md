# 360GS Prototype v0.1b

360°写真と3D Gaussian Splattingを、専門的な設定なしでブラウザ上から確認するためのプロトタイプです。

## この版でできること

### 360°写真

- JPEG / PNG / WebPの360°写真をファイル選択またはドラッグで読み込む
- 画像の縦横比を確認し、360°写真らしくない画像をわかりやすく警告する
- ブラウザ内で自由に見回す

### 3DGS

- 3D Gaussian Splattingの `.ply`、`.compressed.ply`、`.sog` を選択またはドラッグで読み込む
- 読み込んだ3D空間をドラッグで回転し、ホイールで拡大縮小する
- モデルの大きさを自動確認し、最初のカメラ位置を自動調整する
- PlayCanvas公式のサンプル3Dで、3DGSファイルを持っていなくても動作確認する

### プライバシー

自分で選択した360°写真と3DGSファイルはサーバーへアップロードせず、端末内のブラウザだけで読み込みます。

## この版ではまだできないこと

- 360°動画から3DGSを自動生成する
- Cloudflare R2へ保存する
- メール認証で限定共有する
- 作成した3DGSをオンライン上で永続保存する

## 使い方

1. GitHub Pagesの360GSを開く
2. 「360°写真を見る」または「3DGSファイルを見る」を選ぶ
3. ファイルを選ぶ
4. ブラウザ上で操作する

3DGSファイルを持っていない場合は「サンプル3Dで試す」を押すだけで確認できます。

## 技術構成

- HTML / CSS / JavaScript
- Photo Sphere Viewer 5.15.0
- Three.js 0.179.1
- PlayCanvas Engine 2.21.4

利用者が理解する必要のない専門用語や設定項目は通常画面から隠します。今後も「ファイルを選ぶ → 自動処理 → 見る → 必要なら共有する」という操作を基本にします。
