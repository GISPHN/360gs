# 360GS Prototype v0.1a

360GSの最初の動作版です。

## この版でできること

- 360°写真をファイル選択またはドラッグで読み込む
- 画像の縦横比を確認し、360°写真らしくない画像をわかりやすく警告する
- 360°写真をブラウザ内で自由に見回す
- 端末のWebGLとWebGPU対応状況を簡単な日本語で表示する
- 選択した画像をサーバーへアップロードせず、ブラウザ内だけで扱う

## この版ではまだできないこと

- 360°動画から3DGSを生成する
- 3DGSファイルを表示する
- Cloudflare R2へ保存する
- メール認証で限定共有する

これらは次の開発段階で追加します。

## 使い方

1. Webページを開く
2. 「360°写真を見る」を押す
3. 「写真を選ぶ」を押す
4. Insta360 Studioなどから書き出した360°写真を選ぶ
5. 画面をドラッグして見回す

専門的な設定は不要です。

## 技術構成

- HTML / CSS / JavaScript
- Photo Sphere Viewer 5.15.0
- Three.js 0.179.1

Photo Sphere ViewerはMIT Licenseです。

## 設計方針

利用者が理解する必要のない専門用語や設定項目は通常画面から隠しています。
今後も「ファイルを選ぶ → 自動処理 → 見る → 必要なら共有する」という操作を基本にします。
